# 예시: 인기상품 카테고리 분류 PROMPT.txt

홈쇼핑모아 기획전 인기상품의 카테고리를 자동 분류하는 프롬프트입니다.

---

## 1단계: 기본 프롬프트

상품명 목록을 받아 카테고리를 분류하는 기본 버전입니다.

````
[카테고리 목록]
```
의류,이미용품,생활,식품,패션잡화,건강,가전,여행/렌탈,가구
```

[요구사항]
- 상품명을 보고 그에 대응하는 카테고리를 직관적으로 파악
- 상품명 표시 없이 카테고리만 같은 순서대로 나열
- 시트에 복사해서 붙여넣기 쉬운 형태로 정리해서 출력 (아래 예시 참고)

[출력 예시]
```
의류
이미용품
...
```

상품명 목록을 줄 테니까 위 요구사항에 맞춰 출력해줘.
````

> **구조 설명**
>
> - `[카테고리 목록]` — 분류 기준을 데이터 영역으로 명확히 구분
> - `[요구사항]` — 해야 할 일을 목록 형태로 정리
> - `[출력 예시]` — 원하는 출력 형식을 구체적으로 제시

---

## 2단계: 테스트

이 프롬프트를 ChatGPT에 보내고, 이어서 상품명 40개를 붙여넣어 테스트합니다.

**테스트 상품 (일부)**:

| 상품명 | 기대 카테고리 |
|---|---|
| CK 캘빈클라인 퍼포먼스 24FW 패딩 우븐셋업 3종 | 의류 |
| 동국제약 마데카크림 시즌7 | 건강 |
| LOMA 너리싱 샴푸3+컨디셔너1 | **생활** |
| 미닉스 음식물 처리기 더플렌더 | 가전 |

---

## 3단계: 비교 — 차이 발견

AI 출력과 내가 직접 분류한 결과를 비교합니다.

| 상품명 | 내 분류 | AI 분류 | 일치? |
|---|---|---|---|
| LOMA 너리싱 샴푸3+컨디셔너1 | 생활 | **이미용품** | X |

**분석**: 샴푸는 일반적으로 이미용품이지만, 이 회사의 분류 체계에서는 "생활"에 속합니다. AI는 일반 상식으로 분류했기 때문에 회사 고유의 분류 기준을 알 수 없습니다.

---

## 4단계: 프롬프트 수정

차이 원인을 파악한 후, **암묵적이었던 분류 기준을 명시적으로** 추가합니다.

````
[카테고리 목록]
```
의류,이미용품,생활,식품,패션잡화,건강,가전,여행/렌탈,가구
```

[요구사항]
- 상품명을 보고 그에 대응하는 카테고리를 직관적으로 파악
- 상품명 표시 없이 카테고리만 같은 순서대로 나열
- 시트에 복사해서 붙여넣기 쉬운 형태로 정리해서 출력 (아래 예시 참고)
- 샴푸나 비누 같은 제품은 "생활"로 분류할 것

[출력 예시]
```
의류
이미용품
...
```

상품명 목록을 줄 테니까 위 요구사항에 맞춰 출력해줘.
````

> **변경점**: 요구사항에 `샴푸나 비누 같은 제품은 "생활"로 분류할 것` 한 줄 추가
>
> **원리**: AI가 틀린 건 "몰라서"가 아니라, 우리 회사의 분류 기준이 일반 상식과 다르기 때문입니다. 이런 **암묵적 요구사항을 명시적으로** 적어주면 해결됩니다.

---

## 핵심 교훈

> **프롬프트는 한 번에 완성되지 않는다 — 테스트하고 고치는 과정이 핵심**

작성 → 테스트 → 비교 → 수정 → 반복. 이 사이클이 프롬프팅의 본질입니다.

---

## 프롬프트 작성 팁

| 팁 | 예시 |
|---|---|
| 데이터 영역을 명확히 구분 | 카테고리 목록, 상품명 등을 본문과 분리 |
| 요구사항은 리스트 형태로 | `- 항목1`  `- 항목2` |
| 중요한 조건은 **강조** | `**중요!** 상품명은 강조 표시해야 함` |
| 암묵적 요구사항을 명시적으로 | 회사 고유의 분류 기준, 예외 규칙 등 |
| 입/출력 예시 제공 | `[입력 예시]`와 `[출력 예시]`로 기대 결과를 보여줌 |
| 첨부 파일은 명확히 참조 | `첨부한 파일 1: 상품목록.csv` |
