# Session 04 — 마이크로툴링

## 실습 자료

### 문제 분해 인터뷰어 (`big-picture-interviewer.md`)

복잡한 업무 문제를 AI로 해결 가능한 하위 문제로 분해하는 메타 프롬프트입니다. 새 ChatGPT/Gemini 대화에 붙여넣고, 해결하려는 문제를 설명하면 실행 가능한 계획을 받을 수 있습니다.

[big-picture-interviewer.md 보기](./big-picture-interviewer.md)

### 마이크로 도구 인터뷰어 (`micro-tool-interviewer.md`)

반복 업무를 자동화하는 HTML 마이크로 도구의 사양서를 만들어주는 메타 프롬프트입니다. 새 ChatGPT/Gemini 대화에 붙여넣고, 자동화하고 싶은 작업을 설명하면 AI 코딩 어시스턴트에게 전달할 사양서를 받을 수 있습니다.

[micro-tool-interviewer.md 보기](./micro-tool-interviewer.md)

### PDF 페이지 분리기 사양서 (`pdf-splitter-spec.md`)

마이크로툴링 데모용 HTML 마이크로 도구 사양서입니다. PDF를 업로드하면 페이지별로 분리하여 ZIP으로 다운로드합니다.

[pdf-splitter-spec.md 보기](./pdf-splitter-spec.md)

### XLSX 텍스트 파서 사양서 (`xlsx-parser-spec.md`)

마이크로툴링 데모용 HTML 마이크로 도구 사양서입니다. XLSX 템플릿과 텍스트를 입력하면 정규식으로 데이터를 추출하여 템플릿에 자동 입력합니다.

[xlsx-parser-spec.md 보기](./xlsx-parser-spec.md)

### 인터뷰 피커 (`interview-picker.md`)

인터뷰 대화록을 평가하여 우수 참여자를 선정하고, 드럼롤 → 슬롯머신 → 폭죽 연출이 포함된 당첨 발표용 HTML 페이지를 생성하는 프롬프트입니다. ChatGPT에 붙여넣고 인터뷰 대화록 파일을 첨부하면, 브라우저에서 바로 열 수 있는 단일 HTML 파일을 출력합니다.

[interview-picker.md 보기](./interview-picker.md)
