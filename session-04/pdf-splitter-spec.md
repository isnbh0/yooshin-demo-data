# PDF 페이지 분리기 — HTML 마이크로 도구 사양서

## 개요

PDF 파일을 업로드하면 각 페이지를 개별 PDF 파일로 분리하여 ZIP으로 다운로드하는 도구.

## 입력

- **파일 형식**: PDF (`.pdf`)
- **제한**: 단일 파일 업로드
- **파일 크기**: 제한 없음 (브라우저 메모리 범위 내)

## 처리 과정

1. 사용자가 PDF 파일을 업로드 (드래그 앤 드롭 또는 파일 선택)
2. PDF 파일을 읽어 총 페이지 수를 표시
3. 각 페이지를 개별 PDF 파일로 분리
4. 분리된 파일들을 ZIP으로 압축
5. ZIP 파일 자동 다운로드

## 출력

- **파일 형식**: ZIP (`.zip`)
- **내용물**: 페이지별 개별 PDF 파일
- **파일명 규칙**: `[원본파일명]_page_001.pdf`, `[원본파일명]_page_002.pdf`, ...
- **ZIP 파일명**: `[원본파일명]_pages.zip`

## UI 구성

- **제목**: "PDF 페이지 분리기"
- **파일 업로드 영역**: 드래그 앤 드롭 + 클릭 파일 선택
- **상태 표시**:
  - 파일 선택 전: 안내 문구
  - 파일 선택 후: 파일명, 페이지 수 표시
  - 처리 중: 진행률 표시 (예: "3/10 페이지 처리 중...")
  - 완료: 다운로드 완료 안내
- **분리 버튼**: 파일 선택 후 활성화
- **초기화 버튼**: 새 파일 작업 시 상태 리셋

## 예외 처리

- PDF가 아닌 파일 업로드 시 오류 메시지
- 빈 PDF (0페이지) 업로드 시 오류 메시지
- 1페이지 PDF: 정상 처리 (1개 파일이 든 ZIP 생성)
- 손상된 PDF: 파싱 실패 시 오류 메시지

## 기술 참고

- 단일 HTML 파일 (서버 불필요)
- 필요한 외부 라이브러리:
  - `pdf-lib` (PDF 파싱 및 페이지 분리): `https://unpkg.com/pdf-lib/dist/pdf-lib.min.js`
  - `JSZip` (ZIP 압축): `https://unpkg.com/jszip/dist/jszip.min.js`
  - `FileSaver.js` (파일 다운로드): `https://unpkg.com/file-saver/dist/FileSaver.min.js`
