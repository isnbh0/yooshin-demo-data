# XLSX 텍스트 파서 — HTML 마이크로 도구 사양서

## 개요

참조 XLSX 템플릿과 텍스트 블록을 입력하면, 텍스트에서 정규식으로 데이터를 추출하여 템플릿 셀에 자동 입력한 XLSX 파일을 생성하는 도구.

## 사용 시나리오

거래처에서 이메일이나 문서로 받은 비정형 텍스트(견적서, 발주서, 정산 내역 등)를 사내 표준 양식(XLSX)에 옮겨야 할 때 사용. 현재는 텍스트를 눈으로 읽고 셀에 하나씩 복사-붙여넣기하는 작업을 자동화한다.

## 입력

### 1. 참조 XLSX 템플릿

- **파일 형식**: XLSX (`.xlsx`)
- **역할**: 출력 파일의 구조(셀 위치, 서식)를 정의
- **요구사항**: 데이터를 채울 셀에 `{{패턴이름}}` 형식의 플레이스홀더가 있어야 함

### 2. 텍스트 블록

- **입력 방식**: 텍스트 영역에 직접 붙여넣기
- **내용**: 이메일 본문, 문서 내용, 또는 기타 비정형 텍스트

## 처리 과정

1. 사용자가 XLSX 템플릿을 업로드
2. 템플릿에서 `{{패턴이름}}` 플레이스홀더를 자동 감지하여 목록 표시
3. 각 플레이스홀더에 대한 정규식 패턴을 자동 생성 (사용자가 수정 가능)
4. 사용자가 텍스트 블록을 붙여넣기
5. 각 정규식으로 텍스트에서 데이터를 추출하여 미리보기 표시
6. 사용자가 확인/수정 후 "생성" 버튼 클릭
7. 템플릿의 플레이스홀더를 추출된 데이터로 교체한 XLSX 파일 다운로드

## 출력

- **파일 형식**: XLSX (`.xlsx`)
- **내용**: 템플릿 구조를 유지하면서 플레이스홀더가 추출 데이터로 교체된 파일
- **파일명**: `[원본템플릿명]_filled.xlsx`

## 플레이스홀더 규칙

| 플레이스홀더 | 설명 | 기본 정규식 예시 |
|---|---|---|
| `{{회사명}}` | 회사/거래처 이름 | `(?:주\|㈜)?[가-힣A-Za-z]+(?:주식회사)?` |
| `{{날짜}}` | 날짜 | `\d{4}[.\-/]\d{1,2}[.\-/]\d{1,2}` |
| `{{금액}}` | 금액 (콤마 포함) | `[\d,]+원?` |
| `{{사업자번호}}` | 사업자등록번호 | `\d{3}-\d{2}-\d{5}` |
| `{{담당자}}` | 담당자 이름 | `[가-힣]{2,4}` |
| `{{전화번호}}` | 전화번호 | `\d{2,3}-\d{3,4}-\d{4}` |
| `{{이메일}}` | 이메일 주소 | `[\w.]+@[\w.]+` |
| `{{커스텀:설명:패턴}}` | 사용자 정의 | 사용자가 직접 정규식 입력 |

## 예시: 견적서 텍스트 → 정산 양식

```

발행처: ㈜한빛산업
사업자등록번호: 123-45-67890
담당자: 김미영 대리
연락처: 02-555-1234
이메일: kim.my@hanbit.co.kr

수신: 유신엔지니어링㈜
담당자: 박준호 과장

품목:
1. A4 복사용지 (80g, 2,500매) - 단가 25,000원 × 20박스 = 500,000원
2. 컬러 레이저 토너 (호환) - 단가 45,000원 × 5개 = 225,000원

공급가액: 830,000원

합계: 913,000원

납품 예정일: 2025.01.22
```

## UI 구성

- **제목**: "XLSX 텍스트 파서"
- **좌측 패널**:
  - XLSX 템플릿 업로드 영역 (드래그 앤 드롭 + 파일 선택)
  - 감지된 플레이스홀더 목록 (각각에 정규식 편집 필드)
- **우측 패널**:
  - 텍스트 입력 영역 (붙여넣기용, 큰 텍스트 영역)
  - 추출 결과 미리보기 테이블 (플레이스홀더 → 추출값)
  - 매칭 하이라이트: 텍스트 영역에서 매칭된 부분 강조 표시
- **하단**:
  - "추출 미리보기" 버튼
  - "XLSX 생성" 버튼 (미리보기 확인 후 활성화)
  - 초기화 버튼

## 예외 처리

- XLSX가 아닌 파일 업로드 시 오류 메시지
- 플레이스홀더가 없는 템플릿: "플레이스홀더(`{{...}}`)를 찾을 수 없습니다" 안내
- 정규식 매칭 실패: 해당 필드를 빨간색으로 표시, "매칭 결과 없음" 표시
- 여러 매칭 결과: 첫 번째 매칭을 기본 선택, 드롭다운으로 다른 매칭 선택 가능
- 텍스트 미입력 시 "추출" 버튼 비활성화
